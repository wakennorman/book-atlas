  `--virtual-time-budget` 能快进 CSS 动画再截图。本机**别用 `npm install -g` 装大包**（agent-browser 跑了 23 分钟最后
  `npm error network proxy` 失败，还在 `node/versions/22.22.2-3/node_modules/` 留了 8.6M 残缺目录，已手动删掉）。
- 交付预览页：`assets/logo-candidates/c1-final.html`（静态 vs 动画并排 + 用途说明）。
- 给用户的结论：动画 SVG 当网页/README/开场用；favicon、PWA manifest 图标必须用静态版（平台不播动画）。
