📖 怎么用 · 5 分钟上手

每条都可以点「试一下」，立刻在这一页的图上做给你看。

① 点一个圆点，看这个人 点节点＝人物档案（身份、结局、与谁有关）；点连线＝关系类型 + 「定义这段关系的小事件」。圆越大＝关系越多；圆＝男，圆角方＝女。
② 用「字 / 号 / 俗称 / 别的译本」也能搜到人 三国可以搜「孔明 / 云长 / 孟德」，百年孤独可以搜「乌苏拉 / 雷贝卡」，罪与罚可以搜「索尼娅」。搜到被折叠的人时会自动展开那一层并定位过去。
③ 人太多看不清：三板斧 + 一键看清 ① 「次要人物」默认收起（只跟一两个人有关的先不画）；② 右上「人数」切主要 / 中等；③ 点人物 → 面板里「🎯 1 跳」只看他的圈子（可扩到 2 跳）。
最后按 「看清（1:1）」：跳到节点原始大小、对准关系最多的人——放得越大，露出的名字越多（像地图分级）。滚轮缩放、在图上按住拖动平移、在图的空白处双击复位。
④ 拖动节点：把一个人拉出来，专门看他的线 点「拖动节点：开」，然后按住任意圆点拖动，就能把他挪开（图上的空白处拖动仍然是平移画布）。松手后先别点别处，位置会留着——这时他身上的线会看得清楚得多；一点空白、缩放或搜索，位置就回到布局（想彻底重排点「重置」）。
⑤ 按地点看戏 左上「📍 全部地点」选一个地点：时间轴只留那里发生的事，图上只亮相关的人；事件卡上的 📍 也能点。地点不做节点（否则关系图会变成一团异构图）。
⑥ 怕剧透：开「剧透保护」 右上角 🔒 选你读到第几章：之后出场的人变灰 🔒、关系不画、事件藏起来。进度存在本机，随时可改。
⑦ 「这两人什么关系？」——最短关系链 底部选两个人 → 本地 BFS 算出最短链，每一跳都给出关系类型和依据事件（不联网、不靠 AI）。
⑧ 虚线 + 「推导」徽章 = 族谱补全 祖孙、叔侄这类关系，原文里常常没有对手戏。虚线表示「由亲子关系推出来的」（面板里会写清推导链，比如由「老何塞→巨人」「巨人→阿尔卡蒂奥」推出）。不想要就点「族谱补全：隐藏」。
⑨ 自己整理一本（本地编辑器） 右上「✏️ 编辑」：地点/人物/关系/事件增删改、本地校验、内嵌实时预览；还能上传整本书（txt / md / html / epub / pdf）自动分章、逐章出 AI 草稿再合并去重。数据只存在你这台机器。 打开编辑器
⑩ 读到哪儿了：第 N 章的世界 右侧「📖 第 N 章」：这一章谁初次登场、新增了哪些关系、发生什么事件、在哪儿发生；还会告诉你下一章将解锁什么。翻到哪一章，就用「✓ 我读到这一章了」把进度推上去。
面板里的「🕰 时间旅行」＋滑块：把图谱拨回第 N 章——只画当时已经发生的关系（同盟→反目这类会随时间切换），不会改你的真实阅读进度；开着剧透保护时最多拨到"读到的那一章"。
⑪ 导出与分享 右上「⬇️ 导出」：① 单文件 HTML——一本书连图带数据打包成一个文件，发给别人双击就能看；② 分享图 PNG；③ 打印版 SVG（矢量，可打印成海报或转 PDF）；④ 数据 JSON。导出的内容跟随你当前的筛选与剧透进度。
⑫ 只看亲缘线 / 只看对立线（关系过滤） 工具栏「关系：全部」里可以勾类型：血缘、婚姻·姻亲、收养·抚养·继亲、结义、无亲缘标注，以及按线条（实线/虚线/点线）。配三个快捷键：只看亲缘（当家族树用）、只看对立·伤害、全部重置；底部的「两人关系」也会跟着过滤。
⑬ 人物志与人物卡 点任意人物：面板里除了档案与关系，还有「他/她的一生（按章）」——按章号排的事件、地点与原文引文；点「🖼 人物卡」可把这个人导成一张 PNG（身份、结局、关键关系与依据事件），适合发想法。
⑭ AI 讲解（不剧透） 跑完「两人关系」或点开某个人后，面板里会有「🤖 讲一遍（不剧透）」：它只把你已经读到的资料（关系链、依据事件、人物档案）交给模型，结局与未解锁内容一律不发，提示词也钉死"只讲第 N 章之前"。没配过 Key 会先弹设置（与编辑器共用，只存本机）。

随时点「复位视图」或在图的空白处双击回到全貌；点任意一个人也会把视野拉回他身上。万一画布被拖到看不见了，图中间会浮出「画布拖到视野外了 · 点这里复位」。想再打开这份说明，点右上角「📖 怎么用」。

🤖 AI 讲解设置

讲解**只使用你已经读到的部分**：资料先在本地按进度过滤（人物结局、未解锁的关系与事件都不会发出去），提示词里也钉死了"只讲第 N 章之前"。不会上传原著正文；Key 只存在你这台机器（与编辑器共用同一份配置）。

DeepSeek 官方端点允许浏览器直连；换成别的端点若报 CORS，就用编辑器里的命令行方式。
